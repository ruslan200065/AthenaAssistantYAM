# Справочная ONNX-модель «Афина»

Здесь лежит исходная ONNX-модель, которую пользователь передал для проекта:

- `Athenah_20260524_205828.onnx` — 3 × Gemm + 2 × LayerNorm, вход `[1,16,96]`
  (16 кадров по 96 признаков openWakeWord), выход `[1,1]` с сигмоидой.

Это **не готовая модель для установки**. На записях пользователя она
срабатывала только на 1 из 11 дублей, поэтому в `.yampkg` не входит и
автоматически не устанавливается. Рабочая модель обучается на самой станции
через UI (`http://<station>:8781/`).

Для справки модель можно сконвертировать в формат приложения:

```sh
python tools/convert_onnx.py \
  models/Athenah_20260524_205828.onnx \
  /tmp/athena.json
```

TFLite-вариант не используется: приложению не нужен TFLite Runtime, а ONNX
конвертируется в обычный JSON и считается встроенным Go-кодом. Конвертация
сохраняет архитектуру, но не делает модель подходящей под другой голос.

## Обратная конвертация: обученная модель → ONNX

Модель, обученную на станции (`model.json` с блоком `head`), можно отдать
другой колонке в виде ONNX с тем же интерфейсом `[1,16,96] -> [1,1]`:

```sh
python tools/head_to_onnx.py \
  /path/to/model.json \
  /path/to/model.onnx
```

Скрипт проверяет результат через ONNX Runtime и сравнивает его с JSON-моделью.
Имена входов/выходов совпадают со справочной ONNX: `onnx::Flatten_0` и `39`.
