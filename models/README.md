# Готовая модель «Афина»

Здесь лежит исходная ONNX-модель, которую пользователь передал для проекта:

- `Athenah_20260524_205828.onnx` — 3 × Gemm + 2 × LayerNorm, вход `[1,16,96]`
  (16 кадров по 96 признаков openWakeWord), выход `[1,1]` с сигмоидой.

Для станции она сконвертирована в `plugin/models/athena.json`:

```sh
python tools/convert_onnx.py \
  models/Athenah_20260524_205828.onnx \
  plugin/models/athena.json
```

TFLite-вариант не используется: приложению не нужен TFLite Runtime, а ONNX
конвертируется в обычный JSON и считается встроенным Go-кодом.

Модель обучена под конкретный голос. Если она плохо реагирует на ваш голос,
переобучите слово в UI (`http://<station>:8781/`); готовая модель при этом
остаётся в пакете и не перезаписывает уже обученную.
